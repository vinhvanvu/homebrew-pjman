# homebrew-pjman

The Homebrew tap for [pjman](https://github.com/vinhvanvu/pjman), a context graph for product development.

```bash
brew install vinhvanvu/pjman/pjman
brew upgrade pjman
```

`Formula/pjman.rb` is written by pjman's release from the package it published to npm. It is never edited by hand: the next release overwrites it.
